# CircularOS

Work in `app/`. Never read or print credentials unless explicitly needed for an authorized configuration action. Never commit `.env*`, `.dev.vars*`, API keys, user photographs, model response bodies containing user data, or deployment credentials.

Before delivery run `npm test`, `npx tsc --noEmit`, and `npm run build` from `app/`. Keep the Sites Vite integration intact. All live Meta calls are server-only. Do not silently substitute fixtures after provider failures. Clearly label prepared examples.

Decision policy must remain deterministic, versioned, and auditable. User edits invalidate an existing plan. Hazardous/electronic materials require specialized handling. Do not invent municipal acceptance, collection locations, carbon savings, or recycling outcomes. City is context, not verified service coverage.

Cursor Agent can perform read-only review after login. Codex owns integration. Keep tasks bounded; do not have multiple agents edit the same files.
